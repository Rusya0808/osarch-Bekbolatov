Build 1 — Accountant



Load: Office applications, heavy Excel spreadsheets, accounting software, email.

Bottleneck: Data storage reliability and startup speed. Basic calculations do not require a powerful processor, but a slow drive will stall the whole system.

Trade-off: We took a basic Intel Core i3-12100 processor instead of more expensive alternatives. The saved money allowed us to install a reliable 1TB M.2 SSD and a good IPS monitor to prevent eye strain.

Total: 292,000 KZT (budget.csv)



Build 2 — Sales Manager



Load: CRM in a browser, 30–40 open tabs, Excel, 4 hours of video calls a day — often all at once.

Bottleneck: Memory, not CPU. Chrome with 40 tabs and an active Zoom call eats up 11–12 GB. On 16 GB, the machine might start swapping during heavy multitasking.

Trade-off: Took a Ryzen 5 instead of a Ryzen 7, and spent the saved money on 32 GB of RAM instead of the standard 16 GB. The CPU idles in this role; the memory does not.

Total: 311,000 KZT (budget.csv)



Build 3 — Web Developer



Load: Local servers, databases, multiple Docker containers, heavy IDEs (WebStorm/IntelliJ), and dozens of documentation tabs.

Bottleneck: CPU thread count and memory capacity. Spinning up multiple containers instantly claims available resources.

Trade-off: We chose a mid-range GPU (RTX 4060 Ti) to allocate the maximum budget into a powerful Intel Core i7-13700 CPU and a massive 64 GB of DDR5 RAM.

Total: 925,000 KZT (budget.csv)



Build 4 — Designer



Load: 3D rendering, working with heavy source files in Adobe Creative Cloud (Photoshop, Illustrator, Premiere), color correction.

Bottleneck: VRAM, GPU rendering performance, and monitor color accuracy.

Trade-off: Took an Intel Core i5-13600K instead of an i7/i9 to free up the budget for a powerful RTX 4070 (12GB) GPU and a professional 4K ASUS ProArt monitor for accurate color work.

Total: 1,075,000 KZT (budget.csv)
